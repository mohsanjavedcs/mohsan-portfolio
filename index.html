STATISTICS & PROBABILITY

API Performance Profiler

A university project that measures and analyzes the response times of backend API endpoints. It compares a fast endpoint with an endpoint that introduces random delays, then uses statistical measures and visualizations to study their performance. 

endpoints = ["/fast", "/delayed"]
requests_per_endpoint = 1000
analysis = [
    "mean and median",
    "variance and standard deviation",
    "quartiles and outliers"
]
